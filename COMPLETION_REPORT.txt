TECHNICAL SPECIFICATIONS
═══════════════════════════════════════════════════════════════════════════════

MODEL ARCHITECTURE:
  - Base Model: MobileNetV2 (pretrained on ImageNet)
  - Base Parameters: 3.5M (efficient)
  - Input Shape: 224×224×3
  - Base Output: Global feature map
  - GlobalAveragePooling2D Layer
  - Dense(128, activation='relu')
  - Dropout(0.5) for regularization
  - Dense(26, activation='softmax') for 26 classes (A-Z)
  - Total trainable parameters: ~200K

TRAINING CONFIGURATION:
  - Batch Size: 32
  - Epochs: 50 (with early stopping)
  - Optimizer: Adam (learning_rate=0.001)
  - Loss Function: Categorical Crossentropy
  - Metrics: Accuracy
  - EarlyStopping: patience=5 on val_loss
  - ModelCheckpoint: save best on val_accuracy
  - ReduceLROnPlateau: factor=0.5, patience=3, min_lr=1e-7

DATA AUGMENTATION:
  - Rotation Range: 20°
  - Zoom Range: 0.2 (±20%)
  - Shear Range: 0.2 (±20%)
  - Horizontal Flip: True
  - Fill Mode: 'nearest'
  - Rescale: 1/255

HAND DETECTION (MediaPipe):
  - Detection Confidence: 0.7 (adjustable)
  - Tracking Confidence: 0.5
  - Max Hands: 2 simultaneous
  - Keypoints per Hand: 21
  - Detection Speed: ~30ms per frame

PREDICTION FILTERING:
  - Method: Hand count-based logic
  - 1 Hand Allowed: C, I, L, O, U, V (6 classes)
  - 2 Hands Allowed: A, B, D, E, F, G, H, J, K, M, N, P, Q, R, S, T, W, X, Y, Z (20 classes)
  - 0 Hands: Invalid prediction (no output)
  - Renormalization: After zeroing invalid predictions

PREDICTION STABILIZATION:
  - Method: Majority voting
  - Window Size: 5 predictions
  - Implementation: collections.deque with maxlen=5
  - Output: Most common letter in last 5 predictions

PERFORMANCE METRICS:
  - Training Time (GPU): 30-60 minutes
  - Training Time (CPU): 2-4 hours
  - Inference Speed (GPU): 50-100 ms per frame
  - Inference Speed (CPU): 200-500 ms per frame
  - Hand Detection: ~30 ms per frame
  - Total Latency (GPU): <150 ms per frame
  - Memory Usage: ~2GB (training), ~500MB (inference)
  - Expected Accuracy: >90% validation, >95% with filtering
