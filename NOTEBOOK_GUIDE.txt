🚨 TROUBLESHOOTING
================================================================================

Problem: "ModuleNotFoundError: No module named 'tensorflow'"
Solution:
  $ pip install tensorflow

Problem: "CUDA error" (if you have GPU)
Solution:
  Cell 2 will automatically fall back to CPU
  Or: $ pip install tensorflow-cpu

Problem: "Notebook runs very slowly"
Solution:
  • Run on GPU (check Cell 1 output)
  • Use Google Colab with GPU
  • Reduce num_iterations in Cell 6 from 20 to 5

Problem: "Chart not showing"
Solution:
  • Add: %matplotlib inline (at top of notebook)
  • Make sure matplotlib is installed

Problem: "Out of Memory"
Solution:
  • Close other applications
  • Run on GPU-enabled machine
  • Reduce BATCH_SIZE in Cell 2
