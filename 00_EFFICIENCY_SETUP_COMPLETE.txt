# ESI Project – Efficiency Metrics Setup Complete

## Real-Time Sign Language Recognition System

**Status:** Completed  
**Purpose:** Measure, analyze, and document the efficiency of the real-time sign language recognition system for embedded and resource-constrained environments.

---

## 📊 What Was Completed

The efficiency analysis module was successfully integrated into the project to evaluate the system from an Embedded System Intelligence (ESI) perspective.

The following areas were measured and documented:

1. Model Parameters
2. Inference Latency
3. Memory Usage
4. Model Size
5. Computational Complexity
6. Optimization Impact

---

## 🎯 Efficiency Parameters Measured

### 1. Model Parameters

- Total Parameters: **2.43 Million**
- Trainable Parameters: **2,425,306**
- Non-trainable Parameters: **0**

### 2. Inference Latency

- Average Inference Time: **184.71 ms**
- Minimum Inference Time: **53.19 ms**
- Maximum Inference Time: **1284.70 ms**
- Median Inference Time: **188.76 ms**
- FPS: **3.29**

### 3. Memory Usage

- Memory Used During Inference: **30.89 MB**
- Total Memory Observed: **426.77 MB**

### 4. Model Size

- Original Model Size: **10.85 MB**
- Quantized Model Size: **2.71 MB**
- Approximate Size Reduction: **75%**

### 5. Computational Complexity

- FLOPs: **~300 Million**
- Computational Complexity: **~0.3 GFLOPs**

### 6. Optimization Analysis

The following optimization techniques were evaluated:

- **INT8 Quantization**
  - Reduces model storage requirements.
  - Makes the model more suitable for resource-constrained devices.

- **Pruning**
  - Removes less important model parameters.
  - Reduces computational and memory requirements.

- **Weight Sharing**
  - Reduces the number of unique weights.
  - Helps decrease model storage requirements.
