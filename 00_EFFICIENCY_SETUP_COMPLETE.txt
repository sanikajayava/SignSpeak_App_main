## 🚀 Optimization Analysis

The following optimization techniques were evaluated as part of the EIS analysis.

### 🔹 INT8 Quantization

- Reduces model storage requirements.
- Converts model weights to a lower-precision representation.
- Makes the model more suitable for resource-constrained devices.
- Achieves approximately **75% model-size reduction**.

### 🔹 Pruning

- Removes less important model parameters.
- Reduces computational and memory requirements.
- Can improve efficiency while maintaining acceptable model performance.

### 🔹 Weight Sharing

- Reduces the number of unique weights.
- Helps decrease model storage requirements.
- Can improve memory efficiency.
